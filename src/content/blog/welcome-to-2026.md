We just shipped a new evolvegs.com. Same boutique Microsoft consultancy, new platform — and a sharper story about what we actually do in 2026.

## What changed

The previous site served us well, but three things had stopped working for us:

- **Speed.** Marketing pages should load in under a second. A page builder we did not control could not get us there.
- **AI-readiness.** Crawlers, Copilot, and other agents need clean, semantic HTML. Astro gives us that with near-zero JS.
- **Cost and control.** Hosting on **Azure Static Web Apps** keeps the bill predictable, gives us a real CI/CD pipeline via GitHub Actions, and aligns with the same Microsoft stack we ship to our clients.

## What is under the hood

- **Framework:** Astro 4 with the Tailwind integration. Pages are static HTML at build time.
- **Hosting:** Azure Static Web Apps (Free tier), region Global.
- **Source:** GitHub repository, `main` branch.
- **Deployment:** GitHub Actions workflow generated by Azure Static Web Apps.

If you are running a Microsoft 365 shop and your public site is still on a legacy CMS — let us know. The Azure Static Web Apps story is *very* good in 2026.
