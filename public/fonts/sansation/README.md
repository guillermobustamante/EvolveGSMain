# Sansation font files

The brand guidelines specify **Sansation** as the primary typeface, with **Arial** as the first fallback.

Drop the following WOFF2 files into this folder to enable the brand typeface:

- `sansation-light.woff2`
- `sansation-regular.woff2`
- `sansation-bold.woff2`

You can convert the supplied `.ttf` / `.otf` files using
[`fonttools`](https://github.com/fonttools/fonttools) or a web tool like
[transfonter.org](https://transfonter.org/).

Until these files are present, the site renders in **Arial** per the
brand-approved fallback chain — visual layout is unaffected.
